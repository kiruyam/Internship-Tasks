# Internship Tasks – DevOps

This repository contains the tasks completed during my DevOps internship.

The tasks cover Docker, AWS EC2, Terraform, Docker Compose, Ansible, Jenkins, Docker Hub, and GitHub-Jenkins webhook integration.

## Tasks

### Task 1 – Docker Deployment on AWS EC2
Deployed an Nginx website using Docker on an AWS EC2 instance.

Technologies:
- AWS EC2
- Docker
- Nginx

### Task 2 – AWS EC2 Deployment using Terraform
Used Terraform to define and provision an AWS EC2 instance with the required security group configuration and Docker setup.

Technologies:
- AWS
- EC2
- Terraform
- Docker

### Task 3 – Docker Compose
Created a Docker Compose setup for an Nginx static website with development and production environment configuration.

Technologies:
- Docker
- Docker Compose
- Nginx
- Environment variables
- Watchtower

### Task 4 – Docker Deployment using Ansible
Used Ansible to automate Docker installation and Nginx container deployment on an AWS EC2 instance.

Technologies:
- Ansible
- AWS EC2
- Docker
- Nginx

### Task 5 – Jenkins Pipeline with Docker and Docker Hub
Created a Jenkins declarative pipeline that builds a Docker image and pushes it to Docker Hub.

Technologies:
- Jenkins
- Docker
- Docker Hub
- GitHub

Docker Hub image:

`mayuriii12/jenkins-docker-task`

### Task 6 – GitHub and Jenkins Webhook Integration
Configured a GitHub webhook to trigger a Jenkins pipeline automatically when changes are pushed to the repository.

Technologies:
- GitHub
- Jenkins
- Webhooks
- Docker
