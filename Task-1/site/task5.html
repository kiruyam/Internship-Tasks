Task 5 - Jenkins Pipeline with Docker and Docker Hub

Objective

Create a Jenkins pipeline that pulls code from GitHub, builds a Docker image and pushes it to Docker Hub.

Tools Used

AWS EC2, Jenkins, Git, Docker, GitHub and Docker Hub

Pipeline

GitHub → Jenkins → Docker Build → Docker Hub

Process

  1. Configured Jenkins on an AWS EC2 instance.
  2. Connected the Jenkins job to the GitHub repository.
  3. Configured Docker access for Jenkins.
  4. Created a declarative Jenkins pipeline.
  5. Built the Docker image using Jenkins.
  6. Logged in to Docker Hub using Jenkins credentials.
  7. Pushed the image to Docker Hub with build number and latest tags.

Output

The Jenkins pipeline successfully built the Docker image and pushed it to Docker Hub.
