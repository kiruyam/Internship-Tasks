Task 3 - Docker Compose

Objective

Use Docker Compose to run an Nginx static website with separate development and production environments.

Tools Used

Docker, Docker Compose, Nginx and Watchtower

Process

  1. Created a Dockerfile using the Nginx Alpine image.
  2. Created a static website inside the site folder.
  3. Configured development and production environment files.
  4. Used Docker Compose to run the Nginx container.
  5. Tested the development environment on port 8080.
  6. Tested the production environment on port 8081.
  7. Configured Watchtower for container update monitoring.

Output

The Nginx static website was successfully run using Docker Compose in both development and production environments.

Note

During the task, the initial Watchtower image had a Docker API compatibility issue. This was resolved by switching to the Watchtower image used in the final setup.
