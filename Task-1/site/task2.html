Task 2 - AWS EC2 Deployment using Terraform

Objective

Create and configure an AWS EC2 instance using Terraform and install Docker automatically.

Tools Used

AWS EC2, Terraform, Docker and Nginx

Process

  1. Configured the AWS provider and EC2 instance in Terraform.
  2. Created a security group for SSH and HTTP access.
  3. Configured user data to install Docker.
  4. Initialized and validated the Terraform configuration.
  5. Applied the Terraform configuration to create the infrastructure.
  6. Verified Docker and the Nginx container on the EC2 instance.

Output

The Terraform configuration was used to create the EC2 infrastructure and configure Docker and Nginx.
