Task 4 - Docker Deployment using Ansible

Objective

Use Ansible for configuration management to automate Docker installation and Nginx deployment on an AWS EC2 instance.

Tools Used

WSL Ubuntu, Ansible, AWS EC2, Docker and Nginx

Workflow

WSL Ubuntu
     |
     | SSH
     v
AWS EC2 Ubuntu
     |
     v
Docker
     |
     v
Nginx Container
     |
     v
Port 80

Steps Performed

  1. Configured Ubuntu on WSL as the Ansible controller.
  2. Configured the EC2 server in the Ansible inventory.
  3. Tested the connection using the Ansible ping module.
  4. Created an Ansible playbook for Docker installation.
  5. Started and enabled the Docker service.
  6. Pulled the Nginx Docker image.
  7. Ran the Nginx container on port 80.

Commands Used

ansible -i inventory servers -m ping

ansible-playbook -i inventory docker-install.yml

docker images

docker ps

curl http://localhost

Actual Output

The Ansible playbook completed successfully and Docker and Nginx were deployed on the EC2 instance.

Verification

The Nginx container was running and the Nginx Welcome page was successfully accessed through port 80.

Result

Docker and Nginx were successfully deployed using Ansible configuration management.
