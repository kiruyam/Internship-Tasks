Task 4 - Docker Deployment using Ansible

Objective

Use Ansible for configuration management to automate Docker installation and Nginx deployment on an AWS EC2 instance.

Tools Used

WSL Ubuntu, Ansible, AWS EC2, Docker and Nginx

Process

  1. Configured Ubuntu on WSL as the Ansible controller.
  2. Configured the EC2 server in the Ansible inventory.
  3. Tested the connection using the Ansible ping module.
  4. Created an Ansible playbook to install Docker.
  5. Started and enabled the Docker service.
  6. Used the playbook to pull the Nginx image.
  7. Ran the Nginx container on port 80.

Output

Docker and Nginx were successfully deployed on the EC2 instance using the Ansible playbook.
