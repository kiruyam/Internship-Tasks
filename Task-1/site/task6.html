Task 6 - GitHub and Jenkins Webhook Integration

Objective

Connect a GitHub repository with Jenkins using a webhook so that changes pushed to the main branch can trigger the Jenkins pipeline.

Tools Used

GitHub, Jenkins, Webhooks, AWS EC2 and Docker

Pipeline Stages

  1. Checkout
  2. Build
  3. Test
  4. Success

Process

  1. Created a GitHub repository for the task.
  2. Configured the Jenkins job with the GitHub repository.
  3. Configured the GitHub webhook.
  4. Configured Jenkins to respond to the GitHub hook.
  5. Tested the pipeline with changes pushed to the repository.

Output

GitHub and Jenkins were connected using a webhook and the Jenkins pipeline completed the Checkout, Build, Test and Success stages.
