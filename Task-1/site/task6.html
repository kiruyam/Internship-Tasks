Task 6 - GitHub and Jenkins Webhook Integration

Objective

Connect GitHub with Jenkins using a webhook so that changes pushed to the main branch can trigger the Jenkins pipeline.

Tools Used

GitHub, Jenkins, Webhooks, AWS EC2 and Docker

Pipeline Stages

  1. Checkout
  2. Build
  3. Test
  4. Success

Webhook Configuration

A GitHub webhook was configured to send push events to Jenkins.

Steps Performed

  1. Created the GitHub repository.
  2. Configured the Jenkins job with the repository.
  3. Configured the GitHub webhook.
  4. Enabled the GitHub hook trigger in Jenkins.
  5. Pushed a change to the main branch.
  6. Verified the Jenkins pipeline stages.

Actual Output

Checkout
Build
Test
Success

Finished: SUCCESS

Result

GitHub and Jenkins were connected using a webhook and the Jenkins pipeline completed the documented Checkout, Build, Test and Success stages.
